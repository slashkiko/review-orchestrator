# accessibility

Baseline: `fast`. Conditional.

Check semantic roles/names, keyboard access, focus order/restoration, label relationships, state/error announcements, motion/contrast where changed, and equivalent access across pointer/touch/keyboard. Trace interactive state transitions, not just static markup.

Use the project's component/accessibility conventions and applicable platform semantics. A finding identifies the affected user interaction and observable barrier.

Exclude visual taste, unrelated legacy accessibility debt, and non-interactive styling without a changed accessibility property.
