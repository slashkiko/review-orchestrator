# docs-dx

Baseline: `fast`. Conditional.

Review whether users can correctly adopt a changed public API, CLI, configuration, error, migration, or operational workflow. Check examples, defaults, deprecations, error actionability, generated help, and migration ordering against actual behavior.

Report an omission only when the changed contract requires user action or existing documentation becomes false. Cite the affected user surface.

Exclude internal comments, wording taste, implementation documentation with no user consequence, and contract design itself.
